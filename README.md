# 🚀 Space Shooter Game

A simple 2D Space Shooter game made using **Python and Pygame**.

The idea of this game is to control a spaceship, shoot bullets, and destroy the enemies coming towards the player. The game also has moving stars in the background to give it a space-like feel.

## 🎮 Features

- Control a spaceship.
- Shoot bullets to destroy enemies.
- Enemies move towards the player.
- Animated stars in the background.
- Simple and interactive gameplay.

## 🛠️ Technologies Used

- Python
- Pygame

## ▶️ How to Run

1. Clone or download this repository.
2. Make sure Python is installed.
3. Install Pygame:

   ```bash
   pip install pygame
   ```

4. Run the main Python file:

   ```bash
   python main.py
   ```

## 📌 About the Project

This project was made as a way to practise Python programming and understand how games work. While building it, I got to explore game loops, movement, collision detection, and handling game objects using Pygame.
